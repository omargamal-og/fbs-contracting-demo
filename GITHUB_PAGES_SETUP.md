# GitHub Pages setup

1. Create a new GitHub repository, for example `fbs-contracting-demo`.
2. Push this project to the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. The included workflow `.github/workflows/deploy-pages.yml` will build and deploy automatically.
6. After deployment, open the URL shown in the GitHub Pages section.

## Language URLs
- English: `?lang=en`
- Arabic: `?lang=ar`

The selected language is also saved in `localStorage`.
